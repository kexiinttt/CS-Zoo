# OSI

| Layer | Data format | Purpose | Common protocols/devices |
| :---: | :---: | :---: | :---: |
| Application | N/A | Controls applications | SSH, HTTP, FTP, DNS |
| Presentation | N/A | Formats data, such as providing encryption | ASCII, JPEG, MP4, AVI, PNG |
| Session | N/A | Controls sessions and establishes, manages, and terminates application sessions | SQL, AHP, PHP, JSP |
| Transport | Fragment | Provides reliable and best-effort transport | TCP, UDP |
| Network | Packet | Routing and IP addressing | IP, BGP, RIP, OSPF, router |
| Data Link | Frame | Defines frame formatting and framing; supports error detection | Switch |
| Physical | Bit stream | Defines information on the physical transmission medium | IEEE 802, hub |
